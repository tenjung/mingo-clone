## 기존 제한과 검수 범위

Supabase 호스트의 DNS 조회 실패가 계속된다. 따라서 게시판 메뉴의 렌더링과 이동 검증을 실제 데이터 조회·계정 생성·사진 업로드·글 저장 성공 검증으로 해석하면 안 된다. 원격 DB 성공과 RLS 정책은 이번 검사에서 확인 불가이며, 운영 규정과 메뉴 추가 작업에서 원격 설정을 바꾸지 않았다.

실제 일정 자료는 원문 확인 후 입력하는 현재 방식 그대로이며, 가짜 일정은 추가하지 않았다. 문서는 제정 예정안이므로 회원 등급·회비·총회·공식 승인이 확정되었다고 표시하지 않는다. 운영 규정안 열람만으로 회비 수납이나 징계 기능이 작동하지 않는다.
