# 운영 규정 배치

## 문제와 원인

기존 이용 안내는 짧은 환영·출처 안내라서 운영 규정 전체를 찾기 어렵다. 제공된 9쪽 PDF는 장기 보관에는 편하지만 모바일에서 직접 읽거나 원하는 조문을 찾기 불편하다. 원본은 다른 카페 명칭을 쓰는 제정 예정안이며 정회원, 회비, 회계와 총회 조항도 포함한다. 이를 현행 규칙이나 이미 제공되는 기능으로 소개하면 오해를 만든다.

## 대안과 선택

- 게시판 공지 글만 사용: 기존 DB 연결 상태에 영향을 받고 새 공지에 묻힐 수 있다.
- PDF만 연결: 휴대전화에서 확대·외부 뷰어가 필요하고 가입·글쓰기 중에 확인하기 어렵다.
- 독립된 서버 페이지: 고정 주소로 접근하고 글자 크기가 화면에 맞게 바뀐다. 이 방식을 선택한다.

`/rules`를 왼쪽 ‘찐팬카페 안내’의 두 번째 메뉴에 둔다. 핵심 안내 6개를 먼저 보여 주고, 본문은 장별로 펼쳐 읽게 한다. 홈·공지의 기본 안내, 이용 안내, 가입 전 안내, 글쓰기 안내, 하단에서 같은 페이지로 연결한다. 가입이나 글쓰기 중 입력 내용을 잃지 않도록 이 위치의 링크는 새 탭으로 연다.

## 내용 기준

본문 10장 39조와 부칙 3조를 유지한다. 카페 명칭은 현재 브랜드 설정을 사용하며, 확인되지 않은 회사명은 ‘소속사’로 정리한다. 제정일·공식 승인·운영진의 인적 정보는 확정하지 않는다. 운영 규정(안), 시행 전 검토, 회비 납부 안내가 아니라는 사실을 명시한다. 원본 PDF는 저장소의 공개 자산에 포함하지 않는다.

## 비용·성능·유지보수

Server Component와 HTML `details`만 추가한다. 새 패키지·DB·API·클라이언트 상태·수납 기능은 추가하지 않는다. 본문은 `src/data/cafe-rules.ts` 한 곳에서 관리하고, 진입 링크들은 `/rules`만 참조한다. 기존 카페 레이아웃의 인증 확인 흐름은 그대로 사용한다. 확정 공지와 시행 시에는 초안 표시와 조문, 가입·글쓰기 안내를 함께 변경한다.

## 검증

- PDF에서 추출한 42개 조문(부칙 포함), 141개 문단과 화면 자료를 대조했다. 명칭·소속사 표현과 ‘트롯’ 표기, PDF의 강조 기호 제거 외에 본문 누락이 없다.
- 데스크톱·모바일 390px에서 페이지, 장별 펼침, 회비 검토 안내, 홈 진입과 모바일 메뉴를 확인했다. 가로 넘침과 콘솔 경고·오류가 없었다.
- 가입 화면의 규정 링크에 새 창 속성이 있으며 링크 클릭 후 닉네임 입력을 유지했다. 가입·글 등록 제출은 실행하지 않았다. 기존 DB 연결 제한은 이번 변경 범위가 아니다.
- 기존 테스트 10개, 타입 검사, 프로덕션 빌드, diff 공백 검사가 통과했다.
